# PowerBIReportCICD

A repository for Power BI report CI/CD workflows.

## Overview

Use this repository to manage Power BI report assets and the automation used to validate and deploy them across environments.

## Getting started

1. Add your Power BI report files and deployment configuration.
2. Configure the required repository secrets and environment settings for your CI/CD workflow.
3. Run the workflow to validate and deploy reports to the target Power BI environment.

> Update this README with the specific workflow, prerequisites, and deployment steps as the project is configured.
